# Hotel App

Full-stack web application for hotel reservations.

## Features
- User authentication (JWT)
- Hotel listing (CRUD)
- Booking system with date validation
- Payment integration (Stripe)

## Technologies
- Node.js
- Express
- MySQL
- HTML, CSS, JavaScript

## Description
This project allows users to browse hotels and make reservations with real-time validation and payment integration.
